What is a JWT (JSON Web Token)?

JWT is a compact and secure way to transmit information between systems. It is the backbone of modern web authentication. A standard JWT token consists of three Base64-encoded parts separated by dots: the Header, the Payload (containing user data), and the Signature.

Is Decoding the Same as Decrypting?

A common confusion is whether you can "decrypt" a JWT. Most JWTs are only encoded (Base64), not encrypted. This means anyone with the token can use a jwt decoder to see the data inside. Never put sensitive passwords inside a JWT payload!
